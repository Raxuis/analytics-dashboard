# Identity and travel artwork

`raxuis-logo.png` is the owner's supplied R logo, copied from the sibling modern-portfolio project. `passport-crest.svg` is the personal cover ornament built for this project.

`countries/` and `country-catalog.json` use public-domain Natural Earth 1:110m country outlines from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson, prepared on 2026-11-12. Projection and blue stippling are authored for this personal passport; these are geographic data graphics, not scans of official documents.

Interior reference: French ordinary passport specimen https://www.consilium.europa.eu/prado/en/FRA-AO-03004/image-310120.html. Travel vignettes are original personal labels, inspired by adhesive passport permissions such as Japan's https://www.boston.us.emb-japan.go.jp/ENGLISH/VISITING%20JAPAN/landing.pdf. They contain the owner's actual destinations and supplied visit counts, with no invented dates, document identifiers, visa conditions or official seals.


The 177 prepared silhouettes are generated by `scripts/generate-travel-countries.mjs`. Projection parameters are retained in the catalog so city markers match each country. Only active country SVGs are loaded.

`country-iso2.json` maps visitor region codes to these same prepared silhouettes using Natural Earth ISO_A2_EH and ADM0_A3. `register-guilloche.svg` is authored mathematical security linework for the analytics paper, not a scan of an official document.
