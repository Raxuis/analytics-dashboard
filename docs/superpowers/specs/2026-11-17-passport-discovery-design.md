# Découverte du passeport

Direction approuvée par « let's go » : accompagner la première visite par des indices dans l’objet, sans tutoriel bloquant ni changement de direction artistique.

Après le chargement, la couverture se soulève légèrement puis revient. Après la première ouverture, le coin inférieur droit de la feuille se courbe une fois. Sur la première double page de voyage, une onde attire l’attention sur une ville réelle. Un texte bref accompagne chaque indice au-dessus des commandes. Après exploration d’une ville, une indication explique le bouton UV. Les boutons et liens restent utilisables immédiatement ; une interaction interrompt les démonstrations sans tourner de page.

Chaque indice montré est mémorisé séparément dans le stockage local. Un échec de stockage conserve la session utilisable. Une préférence de réduction des animations remplace les mouvements par le texte. Les indications se suspendent pendant les transitions, le menu, le lecteur, les tooltips et lorsque l’onglet est masqué. Aucun son, dépendance supplémentaire, nouvelle donnée personnelle ou déplacement automatique de page.

La couverture et la page retrouvent leur géométrie exacte avant toute navigation. L’animation utilise le rendu à la demande existant et s’arrête après un cycle. Les villes et les visas gardent leurs zones de clic.
